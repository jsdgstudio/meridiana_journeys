# Experience Engine

## The Emotional Arc

Every page on Meridiana follows a deliberate psychological sequence. This is not a sales funnel — it's an **editorial reading experience** that naturally culminates in interest.

### The Five Stages

```
EMOTION → UNDERSTANDING → TRUST → DESIRE → ACTION
```

#### 1. Emotion (Hero Zone)
- **Goal:** Stop the scroll. Create an emotional response.
- **Elements:** Full-bleed image/video, editorial headline, atmospheric overlay
- **Duration:** 3–5 seconds of pure visual impact
- **Copy tone:** Poetic, evocative, minimal — a single powerful statement
- **No:** Buttons in the hero (too early). Let the image breathe.

#### 2. Understanding (Narrative Zone)
- **Goal:** Contextualize the emotion. Tell them *why* this matters.
- **Elements:** Long-form text, pull quotes, editorial rhythm
- **Duration:** Reader-paced. No rush.
- **Copy tone:** Literary, informed, culturally rich
- **No:** Bullet points. Lists. Quick-scan formatting. This is for *readers*.

#### 3. Trust (Detail Zone)
- **Goal:** Answer practical questions without breaking the mood.
- **Elements:** Includes/excludes, itinerary, logistics
- **Duration:** Scan-friendly but still beautifully designed
- **Copy tone:** Clear, confident, warm — not corporate
- **No:** Overwhelming data dumps. Space the details.

#### 4. Desire (Experience Zone)
- **Goal:** Make it tangible. Make them *feel* the experience.
- **Elements:** Experience metrics, signature moments, sensory details
- **Duration:** Brief but impactful
- **Copy tone:** Intimate, sensory, aspirational without being cheesy
- **No:** Hard-sell language. Urgency tactics. Countdown timers.

#### 5. Action (CTA Zone)
- **Goal:** Natural transition to inquiry.
- **Elements:** Warm CTA, contact form, reassurance
- **Duration:** Single clear action
- **Copy tone:** Inviting, zero pressure
- **No:** "Book NOW!", "Limited spots!", aggressive urgency

## UX Principles

### Pacing
- **Slow reading is a feature, not a bug.** The site rewards attention.
- Section transitions should feel like turning a page in a book.
- Generous vertical spacing between sections.
- Animations reveal content — they don't distract from it.

### Scrolling Behavior
- Smooth, parallax-light (subtle, not theme-park)
- Fade-in reveals as content enters viewport
- No scroll-jacking. User controls the pace.

### Navigation
- Minimal, unobtrusive navbar
- Transparent on hero, solid on scroll
- Max 5 items: Home, Journeys, Journal, About, Contact
- No dropdowns. Simplicity.

### Mobile Considerations
- Same editorial quality, adapted layout
- Touch-friendly targets (48px minimum)
- Images load progressively
- Narrative text remains readable (no cramped columns)

## Page-Specific Flow

### Homepage
```
Hero (video + statement)
  → Value Proposition (3 pillars)
  → Featured Tours (2-3 curated picks)
  → How It Works (simple 3-step)
  → CTA (explore journeys)
```

### Tour Detail
```
TourHero (destination image + title)
  → TourNarrative (long-form editorial)
  → TourIncludes (what's in/out)
  → TourItinerary (day-by-day)
  → TourExperience (metrics + highlights)
  → TourPricing (transparent, warm)
  → CTA (request itinerary)
```

### Journeys Grid
```
Page Header (minimal, editorial)
  → Filter/Category (optional, subtle)
  → Tour Cards Grid
  → CTA (custom journey inquiry)
```

## Conversion Philosophy

- **Conversion = inquiry, not transaction**
- We're not selling a product. We're opening a conversation.
- Every CTA should feel like an invitation, not a demand.
- The goal is for the reader to *want* to reach out, not feel pressured to.
