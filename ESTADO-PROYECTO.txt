STACK TECNOLÓGICO
================================================================================
- Framework: Next.js 14+ (App Router)
- Lenguaje: TypeScript (strict mode)
- Estilos: Tailwind CSS 3.4+ (sin custom CSS, todo vía globals.css)
- Animaciones: Framer Motion (NUNCA CSS transitions)
- Deployment: Vercel
- Fuente de contenido: JSON local (Phase 1) → Supabase (Phase 2)
- Tipografías:
  - Headings: Cormorant Garamond (peso 300 light, NUNCA bold)
  - Body/UI: General Sans Variable (200-700)

ANIMACIONES (Framer Motion)
================================================================================
REGLA CRÍTICA: NUNCA usar CSS transitions. SIEMPRE usar Framer Motion.

Patrones comunes:
- fadeUp:       opacity 0→1, y 16→0
- fadeIn:       opacity 0→1 simple
- wordReveal:   cada palabra sube individualmente
- staggerChildren: múltiples items con delay staggered

Easing: [0.25, 0.1, 0.25, 1] para la mayoría
Motion: spring (stiffness: 80, damping: 22) para scroll reveals

ARQUITECTURA DE DATOS
================================================================================
Flujo: JSON → hooks (useContent/useTours) → locale filter → componentes → UI

Frontend hooks:
- useContent:      Lee *.json de content/pages/, retorna contenido + locale
- useTours:        Lee tour JSONs, filtra por locale, retorna tours

Tipos TypeScript: frontend/types/
- Locale = "es" | "en"
- Tour = { id, nombre, descripción, duración, ... }
- HeroContent, AboutPreviewContent, etc.

Bilingual pattern:
interface LocaleString { es: string; en: string; }

En componentes:
const text = content.headline[locale]; ← automático locale switching
